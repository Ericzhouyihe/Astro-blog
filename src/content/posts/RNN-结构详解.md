**RNN 各种结构**：

1. **基础 RNN（单层、单向）**
2. **多层 RNN（Multi-layer / Stacked RNN）**
3. **双向 RNN（BiRNN / Bidirectional RNN）**
4. **多层 + 双向 RNN（Stacked BiRNN）**

我可以按照你现在学 NLP 的方式，从**“一个时间步到底发生什么”**开始，把这几个结构一层层串起来。

先给你一个总览：

```text
                    RNN 的几种结构
                         │
          ┌──────────────┴──────────────┐
          │                             │
       单向 RNN                      双向 RNN
          │                             │
     ┌────┴────┐                   ┌────┴────┐
     │         │                   │         │
   单层      多层                单层      多层
     │         │                   │         │
  基础RNN   Stacked             BiRNN   Stacked BiRNN
```

### ① 基础 RNN：单层 + 单向

比如一句话：

```text
我 → 喜欢 → 学习 → NLP
```

RNN 按时间顺序处理：

```text
x1       x2       x3       x4
↓        ↓        ↓        ↓
RNN →    RNN →    RNN →    RNN
↓        ↓        ↓        ↓
h1       h2       h3       h4
```

核心就是：

```text
h1 = f(x1, h0)
h2 = f(x2, h1)
h3 = f(x3, h2)
h4 = f(x4, h3)
```

也就是：

> **当前输入 x + 上一个隐藏状态 h → 当前隐藏状态 h**

所以 RNN 的核心不是“循环执行代码”这么简单，而是：

> **通过隐藏状态，把前面的信息传递给后面的时间步。**

---

### ② 多层 RNN：不是时间方向变了，而是“竖着叠起来”

单层：

```text
x1 ──→ RNN ──→ h1
x2 ──→ RNN ──→ h2
x3 ──→ RNN ──→ h3
```

多层：

```text
             第2层
        h1² ──→ h2² ──→ h3²
        ↑       ↑       ↑
        │       │       │
        h1¹ ──→ h2¹ ──→ h3¹
             第1层
        ↑       ↑       ↑
        x1      x2      x3
```

所以：

```text
第一层：负责处理输入序列
第二层：处理第一层输出的序列
第三层：继续处理第二层输出
```

注意：

**多层 ≠ 双向。**

多层解决的是：

> **“网络纵向上有多少层 RNN？”**

---

### ③ 双向 RNN：两个方向一起看

普通 RNN：

```text
我 → 喜欢 → 学习 → NLP
→    →      →      →
```

它只能：

> 从左往右看。

双向 RNN：

```text
正向：
我 → 喜欢 → 学习 → NLP
→    →      →      →

反向：
我 ← 喜欢 ← 学习 ← NLP
←    ←      ←      ←
```

于是每个位置都有两个隐藏状态：

```text
正向 h→
反向 h←
```

最后通常拼接：

```text
h = [h→ ; h←]
```

例如处理：

```text
我 喜欢 苹果
```

“苹果”这个词的表示可以同时参考：

```text
左边：我、喜欢

右边：后面的词
```

所以双向 RNN 的核心是：

> **让当前位置同时获得过去和未来的信息。**

---

### ④ 多层 + 双向：你说的“多+双结构”

这个就是把前面两个东西结合起来。

例如：

**2层双向 RNN**

```text
                    第2层
          → RNN → RNN → RNN →
         ↗                    ↘
       ← RNN ← RNN ← RNN ←
                    ↑
                    │
                    │
                    第1层
          → RNN → RNN → RNN →
         ↗                    ↘
       ← RNN ← RNN ← RNN ←
                    ↑
                    │
             x1    x2    x3
```

实际理解的时候不要被图吓到。

你可以拆成：

```text
多层
 ↓
上下叠加

双向
 ↓
每一层里面又有
正向 RNN + 反向 RNN
```

所以：

> **多层 + 双向 = 纵向堆多层，每一层横向都有两个方向。**

---

### 最容易混淆的地方

你可以记这个表：


| 结构         | 解决什么问题       | 方向 | 层数 |
| ------------ | ------------------ | ---- | ---- |
| 基础 RNN     | 建模序列上下文     | 单向 | 1    |
| 多层 RNN     | 增加网络表达能力   | 单向 | ≥2  |
| 双向 RNN     | 同时利用过去和未来 | 双向 | 1    |
| 多层双向 RNN | 深层 + 双向上下文  | 双向 | ≥2  |

还有一个非常关键的概念：

```text
“时间步” ≠ “层”
```

例如：

```text
2层 RNN
处理 10 个词
```

不是说有 20 个 RNN 网络，而是：

```text
时间方向：10 个时间步
纵向方向：2 层
```

所以整个结构可以理解成一个 **“时间 × 层数”** 的网格。

如果你现在正在学 RNN，我建议下一步直接把 **“单层 → 多层 → 双向 → 多层双向”用一个具体的 3 个词的例子，把每个 h 到底传给谁画出来**。这样你后面学 LSTM、GRU、BiLSTM 会非常顺。
